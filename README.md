# 📊 Organizador de Informações para Imposto de Renda

Uma ferramenta desenvolvida integralmente no **Microsoft Excel** para auxiliar na organização, consolidação e conferência das principais informações necessárias à preparação da declaração de **Imposto de Renda**.

A proposta é transformar o Excel em um verdadeiro **agregador de dados**, permitindo que o usuário registre suas informações de forma organizada, padronizada e validada, reduzindo a dispersão de dados e facilitando a conferência das informações antes da declaração.

---

## 🎯 Objetivo

O projeto tem como objetivo centralizar, em um único arquivo, informações que normalmente ficam distribuídas entre documentos, comprovantes, informes de rendimentos e outras fontes.

A ferramenta busca proporcionar uma experiência simples e intuitiva, permitindo que o usuário:

* 📝 Registre informações de forma estruturada;
* 📂 Organize diferentes tipos de informações em categorias;
* ✅ Utilize validações automáticas para reduzir erros de preenchimento;
* 🧭 Navegue facilmente entre as diferentes áreas da ferramenta;
* 🔗 Acesse rapidamente sites e recursos externos por meio de links;
* 🔎 Consulte e confira os dados inseridos;
* 📊 Tenha uma visão consolidada das informações registradas;
* 💾 Mantenha um histórico organizado das informações utilizadas na preparação da declaração.

> **Importante:** a ferramenta tem finalidade de **organização e controle das informações**. Ela não substitui a declaração oficial do Imposto de Renda, nem a análise ou orientação de um profissional especializado.

---

## 🚀 Principais funcionalidades

### 🧭 Menu de navegação

O arquivo conta com uma estrutura de navegação que permite acessar rapidamente as diferentes áreas da ferramenta, tornando a utilização mais simples e intuitiva.

A navegação foi pensada para que o usuário não precise percorrer manualmente diversas planilhas para localizar uma determinada informação.

### 📝 Registro estruturado de informações

As informações são organizadas em áreas específicas, permitindo que cada tipo de dado seja registrado de maneira padronizada.

Essa estrutura facilita tanto o preenchimento quanto a posterior conferência dos dados.

### ✅ Validações automáticas

A ferramenta utiliza recursos nativos do Excel para auxiliar na qualidade dos dados inseridos, incluindo:

* Listas suspensas;
* Validação de campos;
* Padronização de informações;
* Restrições para determinados tipos de preenchimento;
* Alertas para entradas inconsistentes.

O objetivo é minimizar erros de digitação e manter os dados em um formato adequado para utilização posterior.

### 🔗 Links rápidos

O projeto também conta com links de acesso rápido a recursos externos relevantes.

Essa funcionalidade permite que o usuário encontre determinados serviços e páginas sem precisar sair procurando manualmente pelos endereços correspondentes.

### 📊 Organização e consolidação

As informações registradas são reunidas de forma estruturada, permitindo uma visão mais clara dos dados que já foram informados e daqueles que ainda precisam ser levantados.

Essa abordagem facilita o processo de preparação da declaração e reduz a possibilidade de esquecer informações importantes.

---

## 🗂️ Estrutura da ferramenta

O arquivo é dividido em diferentes áreas, cada uma com uma finalidade específica.

Uma estrutura típica do projeto contempla:

| Área                          | Finalidade                                           |
| ----------------------------- | ---------------------------------------------------- |
| 🏠 **Início**                 | Página principal e acesso às funcionalidades         |
| 👤 **Dados pessoais**         | Organização das informações cadastrais               |
| 💰 **Rendimentos**            | Registro dos rendimentos e respectivos informes      |
| 🏦 **Bancos e investimentos** | Organização de informações financeiras               |
| 🏠 **Bens e direitos**        | Controle dos bens e direitos a serem considerados    |
| 💳 **Pagamentos e despesas**  | Registro de informações relevantes para a declaração |
| 📄 **Documentos**             | Controle dos documentos e comprovantes disponíveis   |
| 🔗 **Links úteis**            | Acesso rápido a sites e serviços relacionados        |
| 📊 **Resumo**                 | Consolidação das principais informações registradas  |

> A estrutura acima pode ser adaptada conforme a evolução do projeto e as funcionalidades efetivamente implementadas no arquivo.

## 💡 Conceito do projeto

Mais do que uma simples planilha, a proposta é transformar o Excel em uma **ferramenta de organização pessoal**.

O conceito parte de uma ideia simples:

> **Reunir, organizar e validar as informações ao longo do tempo para tornar a preparação da declaração muito mais simples.**

Em vez de deixar para reunir todos os documentos e informações apenas no período da declaração, o usuário pode utilizar a ferramenta como um ponto central de organização.

---

## 🔐 Organização e confiabilidade dos dados

Como a ferramenta pode conter informações pessoais e financeiras, recomenda-se que o arquivo seja armazenado em local seguro e que sejam adotadas boas práticas de proteção de dados.

O usuário é responsável pelas informações inseridas no arquivo e pela conferência dos dados antes de utilizá-los para fins de declaração.

---

## 📌 Como utilizar

1. Abra o arquivo no **Microsoft Excel**.
2. Acesse a página inicial da ferramenta.
3. Utilize o menu de navegação para acessar cada categoria.
4. Preencha as informações solicitadas.
5. Utilize as listas e validações disponíveis para manter os dados padronizados.
6. Consulte o resumo para conferir as informações registradas.
7. Utilize os links rápidos quando necessário.
8. Antes da declaração, revise todas as informações e documentos registrados.
